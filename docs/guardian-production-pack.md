# Guardian Aegis — production reference pack

Status: **Reference**. This pack creates the first cardboard and EVA mock-up. It is not field certification.

## Drawing set

- `dist/downloads/guardian-template-500mm.svg`: 500 mm full-scale face outline, LED guide and 100 mm print check.
- `dist/downloads/guardian-rear-layout.svg`: A4 rear module/strap layout and physical layer cross-section.

## Starting geometry

| Item | Starting value | Must be verified by |
| --- | ---: | --- |
| Shield diameter | 450–550 mm; default 500 mm | Three-user cardboard fit test |
| LED diffuser guide | 390 mm diameter | LED strip bend radius and visibility |
| Centre boss guide | 116 mm diameter | Front padding and desired silhouette |
| Service cavity | 110 × 85 × 28 mm | Exact selected board/connectors |
| Strap width | 25 mm | Five-minute wear test |
| Target mass | below 1.2 kg | Finished mock-up scale |

## Printing

1. Open the 500 mm SVG in software that supports poster/tile printing.
2. Select **Actual size / 100%** and disable **Fit to page**.
3. Print and measure the 100 mm check bar.
4. Reject the print when the bar differs by more than 1 mm.
5. Tape the pages, transfer only to cardboard, and complete the fit gate before buying final EVA or electronics.

## Safety boundary

Use rounded foam edges and a removable padded service module. Do not add a rigid full-width core, shield-charge gameplay, or intentional body contact. First electronics power-up remains USB-only.
